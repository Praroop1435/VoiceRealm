| Layer | Technology | What you'll learn |
|-------|------------|-------------------|
| Frontend | Next.js, TypeScript, Tailwind CSS | Components, state, streaming UI |
| Backend | Python, FastAPI, Pydantic | APIs, validation, async I/O |
| Database | PostgreSQL | SQL, transactions, indexing, migrations |
| Data access | SQLAlchemy 2.x | ORM, sessions, persistence boundaries |
| Database migrations | Alembic | Safe schema evolution |
| Real-time communication | WebSockets initially; WebRTC when needed | Bidirectional communication |
| Background jobs | Redis + Celery, introduced later | Queues, retries, idempotency |
| Testing | pytest + API integration tests | Correctness and regression prevention |
| Observability | Structured logs, metrics, OpenTelemetry | Debugging and performance measurement |
| Deployment | Docker, then CI/CD | Reproducible environments and releases |
